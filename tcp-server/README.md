# TCP Server на C

Простой многоклиентский TCP-сервер для изучения сетевого программирования.

## Возможности

- Прослушивание порта 8080
- Приём сообщений от клиентов (до 1023 байт)
- Отправка ответа "Hello from server!"
- Бесконечный цикл обработки клиентов

## Стек

| Компонент | Технология |
|-----------|------------|
| Язык | C (C11) |
| Компилятор | GCC |
| API | POSIX sockets (sys/socket.h) |
| Протокол | TCP (AF_INET, SOCK_STREAM) |

## Сборка

```bash
gcc -Wall -Wextra -o tcp_server tcp_server.c
```
## Запуск
```bash
./tcp_server
```
Сервер слушает порт 8080. Для остановки нажать Ctrl+C.
## Использование
```bash
# Отправить запрос через curl
curl http://localhost:8080/

# Или через netcat
echo "привет" | nc localhost 8080
```
