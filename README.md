> 📦 Коллекция сетевых проектов, реализованных на разных языках программирования.

## 📖 О репозитории
`Network-Stack` — это единое пространство для экспериментов, бенчмарков и готовых сетевых решений.  
Каждый подпроект **автономен**: имеет собственные зависимости, систему сборки и документацию. Объединяет их только предметная область — сети, протоколы и коммуникация.
