
# TCP Client-Server на C

Полноценная TCP клиент-серверная система, написанная на языке C с использованием системных вызовов Berkeley Sockets API.

## 🚀 Возможности

### Сервер (`tcp_server.c`)
- Создание TCP-сокета с IPv4
- Опция `SO_REUSEADDR` для быстрого перезапуска без ожидания `TIME_WAIT`
- Привязка к порту 8080 и прослушивание входящих соединений
- Бесконечный цикл обработки клиентов (последовательно)
- Чтение данных от клиентов через `recv()`
- Вывод IP-адреса и порта каждого подключившегося клиента
- Корректное закрытие соединений
- Полная обработка ошибок всех системных вызовов

### Клиент (`tcp_client.c`)
- Подключение к серверу по указанному IP и порту
- Отправка текстового сообщения
- Корректное завершение соединения
- Обработка ошибок на каждом этапе

## 📋 Требования

- GCC компилятор (GNU Compiler Collection)
- POSIX-совместимая ОС (Linux, macOS)
- Стандартная библиотека C

## 🛠 Компиляция

### Сервер
```bash
gcc -Wall -Wextra -o server tcp_server.c
```

### Клиент
```bash
gcc -Wall -Wextra -o client tcp_client.c
```

### Makefile (опционально)
Если создан `Makefile`, можно использовать:
```bash
make all      # Скомпилировать оба файла
make clean    # Удалить исполняемые файлы
```

## 💻 Использование

### Запуск сервера
```bash
./server
```

Сервер начнет слушать порт 8080 и выведет:
```
✅ Сокет успешно создан
✅ Опция SO_REUSEADDR установлена
✅ Структура адреса заполнена
✅ Сокет успешно привязан к порту 8080
👂 Сервер слушает входящие соединения...
```

### Запуск клиента
В другом терминале:
```bash
./client
```

Клиент подключится к серверу и отправит сообщение "Hello from C client!".

### Тестирование с помощью `nc` (netcat)
Вместо клиента можно использовать `nc`:
```bash
nc localhost 8080
Привет от netcat!
# Нажмите Ctrl+D для завершения
```

### Остановка сервера
Нажмите `Ctrl+C` в терминале с сервером.

## 🏗 Архитектура

### Сервер
1. **Создание сокета** (`socket()`) — создание endpoint для сетевого взаимодействия
2. **Настройка опций** (`setsockopt()`) — установка `SO_REUSEADDR` для переиспользования порта
3. **Привязка** (`bind()`) — привязка сокета к IP-адресу и порту
4. **Прослушивание** (`listen()`) — перевод сокета в режим ожидания соединений
5. **Прием соединений** (`accept()`) — блокирующий вызов в бесконечном цикле
6. **Чтение данных** (`recv()`) — получение сообщения от клиента
7. **Закрытие** (`close()`) — освобождение ресурсов

### Клиент
1. **Создание сокета** (`socket()`)
2. **Подготовка адреса** — заполнение структуры `sockaddr_in` с IP и портом сервера
3. **Подключение** (`connect()`) — установление TCP-соединения (three-way handshake)
4. **Отправка данных** (`send()`) — передача сообщения серверу
5. **Закрытие** (`close()`)

## 🔍 Ключевые концепции

### Сетевой порядок байтов (Network Byte Order)
- Порты и IP-адреса должны быть в big-endian формате
- `htons()` — конвертация порта из host в network byte order
- `htonl()` — конвертация IP из host в network byte order
- `inet_pton()` — преобразование строкового IP в бинарный формат

### Обработка ошибок
Каждый системный вызов проверяется на возвращаемое значение:
- `< 0` — ошибка, выводится через `perror()` и программа завершается
- `>= 0` — успешное выполнение

### Однопоточная модель
Сервер обрабатывает клиентов последовательно. Пока обрабатывается один клиент (блокирующий `recv()`), новые соединения остаются в очереди `BACKLOG`.

## 🐛 Отладка

