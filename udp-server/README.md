# UDP Server на C

Простой UDP-сервер для изучения сетевого программирования без установки соединения.

## Возможности

- Прослушивание порта 8080 по протоколу UDP
- Приём сообщений от клиентов (до 1023 байт)
- Отображение IP-адреса и порта отправителя
- Отправка ответа "Hello from UDP server!"
- Бесконечный цикл обработки пакетов

## Стек

| Компонент | Технология |
|-----------|------------|
| Язык | C (C11) |
| Компилятор | GCC |
| API | POSIX sockets (sys/socket.h) |
| Протокол | UDP (AF_INET, SOCK_DGRAM) |

## Сборка

```bash
gcc -Wall -Wextra -o udp_server udp_server.c
```

## Запуск

```bash
./udp_server
```

Сервер слушает порт 8080. Для остановки нажать `Ctrl+C`.

## Использование

```bash
# Отправить сообщение через socat
echo "ping" | socat - UDP:localhost:8080

# Или через netcat
echo "ping" | nc -u -w1 localhost 8080
```

## Жизненный цикл сокета

```
socket() → bind() → recvfrom()/sendto() → close()
```

| Функция | Описание |
|---------|----------|
| `socket()` | Создать UDP-сокет (SOCK_DGRAM) |
| `bind()` | Привязать к порту 8080 |
| `recvfrom()` | Принять пакет и узнать адрес отправителя |
| `sendto()` | Отправить ответ конкретному клиенту |
| `close()` | Закрыть сокет |

## Отличия от TCP

| | TCP | UDP |
|---|-----|-----|
| Тип сокета | `SOCK_STREAM` | `SOCK_DGRAM` |
| Установка соединения | `listen()` + `accept()` | Нет |
| Количество сокетов | 2 (серверный + клиентский) | 1 |
| Приём данных | `recv()` | `recvfrom()` |
| Отправка данных | `send()` | `sendto()` |
| Адрес клиента | Из `accept()` | Из `recvfrom()` |
| Гарантия доставки | Да | Нет |
| Порядок пакетов | Сохраняется | Не гарантирован |

## Примечания

- UDP не гарантирует доставку — пакеты могут теряться
- Максимальный размер UDP-пакета: 65535 байт
- `recvfrom()` блокирует выполнение до получения пакета
- Для неблокирующего режима использовать флаг `MSG_DONTWAIT`
